# videoeditor.agency — site source

Plain HTML and CSS. No framework, no build step. What is in this folder is exactly
what is served.

**The deployment runbook is at `DEPLOYMENT-RUNBOOK.md`, one level up — deliberately
outside this folder.**

Everything inside `site\` is **published**. The Mango project kept its runbook in the
equivalent folder and it was readable by anyone at `mangomedia.digital/README.md`,
including its note on the one Cloudflare setting that keeps the research archive
private. That is not a mistake worth repeating.

This stub exists only so the filename is not free for something else to occupy.
There is a `/README.md` redirect in `_redirects` as a second line of defence.

**Do not put internal documentation in this folder.** Anything here is public.

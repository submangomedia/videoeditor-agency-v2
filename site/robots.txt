# ⚠️ THIS FILE IS NOT THE noindex CONTROL. THEY ARE TWO SEPARATE LOCKS.
# ---------------------------------------------------------------------------
# Every page carries its own <meta name="robots" content="noindex, nofollow">
# in its <head>. Both locks have to move, and moving one alone does nothing:
#
#   Open robots.txt while pages still carry noindex   → nothing gets indexed
#   Remove every noindex while robots.txt is closed   → nothing gets crawled,
#                                                       so nothing sees that
#                                                       the noindex is gone
#
# And there is a worse trap, which is why the ORDER matters:
# a crawler blocked by robots.txt CANNOT READ the noindex tag. If a URL is
# blocked in robots.txt but linked from elsewhere, Google can index the URL
# without ever fetching it. So robots.txt is not a reliable way to keep a page
# out of the index — the meta tag is. robots.txt controls CRAWLING; the meta
# tag controls INDEXING.
#
# THE ORDER THAT WORKS AT CUTOVER:
#   1. Lift <meta robots> on the pages that are ready — PAGE BY PAGE.
#   2. Only then open robots.txt and publish the sitemap.
#
#

# ⚠️ THE noindex LIFT HAS NO DRIFT PROTECTION. NEW FINDING, 2026-09-05.
# ---------------------------------------------------------------------------
# tools/sync-shared.mjs synchronises the SHARED:HEADER and SHARED:FOOTER
# blocks ONLY — read its BLOCKS constant. It does not touch <head>.
#
# So the ten <meta robots> tags are ten independent hand edits with no
# checker behind them. `--check` will print "No drift" on a site where one
# page is still noindex, because it is not looking there. That is the exact
# silent failure sync-shared.mjs was written to prevent, in the one place it
# does not cover.
#
# THIS MUST NOT BE FIXED BY MOVING THE TAG INTO A SHARED BLOCK. A shared tag
# makes the lift SITEWIDE, and instructions.md §5 bans that outright: page by
# page, never sitewide. The right fix is a --check-only audit that reports
# which pages still carry noindex. Proposed, not built: tools/ is not in any
# thread's Owns column and T9 will not claim it by writing to it.
#
# UNTIL THAT EXISTS, THE LIFT IS A MANUAL CHECKLIST. T10 opens all ten files

## The rule this folder exists to enforce

**Nothing enters this folder until Masud has approved it.** A file here is what goes
into the HTML, verbatim.

The Mango project's equivalent folder holds five files, of which **four are empty
stubs and one is a partial draft with unfilled brackets** — because copy was written
against decision documents that had never been signed off. Do not repeat that. An
empty folder is honest; a folder of half-finished stubs looks like progress and is
not.

## ⚠️ Brackets

A `[[bracket]]` marks a fact Masud has not supplied. **A file containing a bracket is
not final and does not ship.** Brackets are deliberately conspicuous — `site.css`
has a `.todo` style that renders them in a dashed yellow box — so that one cannot
reach production unnoticed.

**A bracket is always better than an estimate.** Never fill one with a plausible
number to make a page look finished.
